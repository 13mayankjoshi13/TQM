# SIPOC — Hostel Management Process

| SIPOC Element | Hostel Management System |
|---|---|
| Suppliers | Students, Hostel Staff, Hostel Administration, System Administrator |
| Inputs | Student data, room data, allocation request, complaint details, user credentials |
| Process | Register → Validate → Manage → Allocate → Handle Complaints → Monitor |
| Outputs | Student records, room status, allocations, complaint status, logs, quality metrics |
| Customers | Hostel Administration, Hostel Warden, Hostel Staff, Students |

## Core Process

```text
Supplier
  ↓
Input
  ↓
Hostel Process
  ↓
Validation / Control
  ↓
Output
  ↓
Customer
```

The SIPOC will be refined with actual process evidence after the base application is implemented.
