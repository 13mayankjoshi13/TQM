# Software Features and TQM Concepts

| Software Feature | Q09 Role | TQM Concept | Quality Goal |
|---|---|---|---|
| Exception Handling | Required Q09 feature | Quality Assurance / Error Control | Reduce uncontrolled failures |
| Strict Validation | Required Q09 feature | Poka-Yoke | Prevent errors at source |
| Module Tests | Required Q09 feature | Quality Control | Detect defects before release |
| Bug Tracker | Required Q09 feature | Fact-Based Decision Making | Track and analyze defects |
| Error Logs | Required Q09 feature | Monitoring | Create evidence of failures |
| Audit Logs | Supporting feature | Traceability / Monitoring | Record important actions |
| Room Allocation Controls | Baseline process | Process Control | Prevent invalid allocations |
| Complaint Tracking | Baseline process | Customer Focus | Track customer issues |

The five Q09 features are the primary assigned quality-goal implementation. Supporting features are included to satisfy the wider TQM workflow.
