# Fishbone Analysis

## Problem Statement

**Software defects or failures in the Hostel Management System**

## Initial Cause Categories

### People

- Incorrect data entry
- Incomplete understanding of workflow
- Incorrect configuration

### Process

- Missing validation step
- Unclear process transition
- Incomplete exception path

### Software Code

- Logic defect
- Missing exception handling
- Incorrect condition
- Inadequate module test

### Database

- Missing constraint
- Incorrect transaction handling
- Data inconsistency

### Infrastructure

- Database unavailable
- File access problem
- Runtime/environment issue

### Measurement

- Error not logged
- Defect not categorized
- Test evidence missing

Actual root causes will be updated using evidence from the defect log and testing.
