# Critical to Quality (CTQ) Tree

## Customer Need: Reliable Hostel Management

```text
Reliable Hostel Management
│
├── Correct Room Allocation
│   ├── Room availability is accurate
│   ├── Duplicate allocation is prevented
│   └── Allocation is traceable
│
├── Effective Complaint Resolution
│   ├── Complaint is recorded
│   ├── Status is maintained
│   └── Resolution is traceable
│
└── Low Software Defect Rate
    ├── Strict validation
    ├── Exception handling
    ├── Module tests
    ├── Bug tracking
    └── Error logging
```

## Measurable CTQs

| CTQ | Measure | Initial Target |
|---|---|---|
| Allocation correctness | Invalid allocations accepted | 0 |
| Complaint traceability | Complaints without status | 0 |
| Error traceability | Detected errors without logs | 0 |
| Test readiness | Critical modules with tests | 100% |
| Bug traceability | Confirmed bugs with tracker entries | 100% |
