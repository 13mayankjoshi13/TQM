# Mission

The mission of the Hostel Management System is to:

- understand customer and user requirements;
- prevent invalid operations at the source;
- control important hostel workflows;
- reduce software bugs through the assigned Q09 quality features;
- maintain traceable records of important activities;
- monitor errors and defects using measurable data;
- apply TQM and SQC tools to real project evidence; and
- continuously improve the system through PDCA.
