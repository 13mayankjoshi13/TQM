## Assigned System Focus

The Hostel Management System focuses on:

* Optimizing room allocation
* Improving complaint resolution

## Quality Problem

Manual or poorly controlled hostel processes can result in:

* Incorrect room allocation
* Duplicate room allocation
* Difficulty identifying available rooms
* Untracked complaints
* Delayed complaint resolution
* Incorrect or incomplete records

## Planned Quality Approach

The system will use software-based controls to prevent and identify these problems.

### Error Prevention

Input validation and business-rule checks will be used to prevent incorrect information from entering the system.

### Process Control

Important operations such as room allocation will follow defined validation and control steps.

### Monitoring

Audit logs, error logs, defect records and quality metrics will be used to monitor system performance.

### Continuous Improvement

Quality data will be analyzed using TQM tools such as FMEA, Pareto analysis, Fishbone analysis and PDCA.

## Initial Quality Direction

The project will aim to create a system where:

**Customer Requirement → Software Feature → Quality Control → Measurement → Improvement**
